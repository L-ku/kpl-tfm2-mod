# KPL SAB 赛制 / KPL SAB League Format

《Teamfight Manager 2》的 KPL（王者荣耀职业联赛）mod，包含三个包：

| 包 | 类型 | 内容 |
| --- | --- | --- |
| `kpl_sab` | 原生 DLL（stable mod SDK） | S/A/B 分组赛制、每档开始随机抽签、每轮清零重分组、统一双败季后赛、最终名次与新闻、国际杯席位修正；中国赛区统一 KPL 风格中文名（持续查重） |
| `kpl_real` | 数据包 | 中国赛区 → KPL 18 支真队 + K 甲；其他赛区 → 真实 LoL 战队；选队列表按实力排序、官方队徽的 64×64 像素风版本、中文 UI |
| `kpl_scout` | 原生 DLL（stable mod SDK） | 替代失效的 Chief Scout：底部栏「Chief Scout」按钮 + 找球员面板（分路评分、潜力/年龄/升级筛选、Solo Rank 资料卡含英雄头像） |

`kpl_sab` 与 `kpl_real` 建议同时启用。只装 `kpl_real` 是换皮；只装 `kpl_sab` 会得到 KPL 赛制但队名仍是原版。`kpl_scout` 可单独使用。

## 赛制

- **开档选队按实力排序**：中国赛区每个联赛里 6 支真 KPL 队按五个位置最强评分之和从高到低排在前面，挂名队排在后面，选队界面一眼能看出强弱。
- **每个赛段开局随机抽签**：春季赛在开档时、夏季赛在 6/22 转会期开启时，把手里的 18 支真队重新随机分成三组（每组 6 队 + 4 支挂名队），并向 18 支真队推送「KPL 春季赛/夏季赛第一轮抽签」新闻。抽签只做一次，第一轮有比赛开打后不会重抽。
- **命名规则**：第一轮显示「KPL 一组 / 二组 / 三组」，第二轮起显示「KPL S组 / A组 / B组」，季后赛统一显示「KPL 季后赛」。只改显示层文本，联赛 ID、赛区、积分都不动。
- **S/A/B 三组**，每组 6 队；第一轮按抽签结果分组，之后按每轮名次重排。
- **每个单循环 15 场**（5 轮 × 3 场，圆桌法），一组打 **3 个单循环 = 45 场**。
- **每轮结束积分清零并重新分组**：第 1 轮打完记名次 → 清零 → 按名次重排 S/A/B → 第 2 轮……第 3 轮结束的名次才是赛季名次。
- **统一季后赛**：S + A 共 12 队，跨两个比赛容器打 **16 场 BO7 双败淘汰**（总决赛、3-4 名赛、5-6 名赛），B 组第二轮后淘汰、不再打自己的季后赛。
- **7-10 名排位赛**：两场 BO7 决定 7-10 名，最终 1-10 名全部由真实比赛结果决定。
- **官方名次新闻**：季后赛结束后向全部 18 支 KPL 队推送「KPL 最终名次」。
- **真实大名单与能力值**：16 支 KPL 队的选手沿用 KPL 官方 2026 大名单（数据来源 kpl.qq.com 官方接口），年龄按真实出生日期。能力值综合 **2023 春至 2026 夏共十个赛季**的数据，用到 11 项指标：分均伤害、分均承伤、伤害占比、承伤占比、经济占比、参团率、KDA、胜率、每分钟击杀、英雄池、英雄胜率。每项指标在「同赛季 + 同分路」内取百分位，再按分路配权重——对抗路重承伤和参团，打野重节奏（参团 + 经济 + KDA），中路和发育路重输出，游走重参团和承伤、几乎不看伤害且经济占比越低越好（让经济）。早期赛季缺的绝对量和胜率、英雄池由逐小局数据重建（已用 2026 官方值交叉验证 108/108 完全一致），赛季间口径差异按同分路均值对齐。生涯荣誉**加分**到数据分之上（不是按比例缩放——旧写法会让没有冠军的选手凭空被扣 30%），荣誉值做对数压缩后按 0.45 的满额加成计入，涵盖各季官方 9 个榜单前五（MVP 次数/总击杀/总助攻/五杀/对位单杀/野怪击杀/中路游走/射手团战伤害/辅助开团）、总决赛冠军首发五人、2023 夏起每届总决赛 FMVP、赛季 MVP（年度总决赛不评选赛季 MVP），以及赛季接口不覆盖的世界冠军杯（含 2023 世冠 FMVP）和挑战者杯（夺冠当年出场 ≥ 20 局才计）；赛事等级年度总决赛 ×1.3、春/夏季赛 ×1.0、世冠 ×1.2、挑战者杯 ×0.9，并统一乘时间权重。结果：小胖 92（2 次 FMVP + 2 次赛季 MVP）、长生 92（2024 年度总决赛 FMVP）、轩染 91（2024 春赛季 MVP）、一诺 90（7 冠 + 2025 年度总决赛 FMVP + 2025 春赛季 MVP + 2023 世冠 FMVP）。只打了几十局的选手会按样本量向中位收缩，不会被小样本吹上去；潜力按年龄区间随机（年轻上限高、老将基本到顶）。名单之外的替补统一降为低能力青训（能力 42–56、潜力 ≤ 80）。
- **名单固定**：同一支队每次开新档都是同一批人、同一套能力。旧版按 `HashMap` 顺序分配名字，每次启动顺序不同，同一支队会换人——1.4.0 已改为按队名和选手 id 固定排序。
- **完整 16 场赛程面板**：引擎给每个比赛容器只有 8 个季后赛卡位，原生联赛页和日历无论如何都只能显示一半（8 场）。所以 `kpl_sab` 在底部栏加了一个「季后赛」按钮（也可按 F8），展开完整 16 场面板：4 列 × 4 行，每场一张照原版对阵卡排版的 327×107 深色圆角卡（40px 队徽槽 + 队名 + 右对齐比分 + 分隔线），卡上方小字标轮次和日期时刻（如 `5/3 17:00`）。开赛新闻同时升级成完整 16 场对阵表，每个季后赛日打完后另推一条「KPL 季后赛战报」（当日两场比分）。面板每秒自动刷新，只读存档、不写任何比赛记录。
- **联赛级别**：S组 / A组 / B组 同为顶级联赛（`division=0`），引擎不会再把 S↔A 当成升降级，也就没有升降级赛新闻、降级履历、董事会降级目标和一级联赛赞助加成的差别。B组↔K甲的升降级保留。
- **挂名队不买人**：挂名队（TCG/ZQ/DSM 等）只是凑数的空壳，但引擎的 AI 会拿着转会预算去抢真 KPL 队的选手。本 mod 每回合把它们的 `transfer_budget` / `salary_budget` 清成 0，报价列表里就不会再出现它们。赛季滚动和赞助结算后会重新清一次。
- **国际杯**：抽签后会修正参赛席位——把挂名队（TCG/ZQ/DSM 等）和重复出现的真队换成没进杯赛的真 KPL 队，只改杯赛记录，不影响积分与升降级。
- **像素风队徽**：18 支 KPL 真队换成官方队徽重绘的 64×64 像素版（KLG、情久用 K 甲官方队徽）；挂名队保留原来的字母块。

## 新手使用说明

### 第一步：装 mod

**最简单的方式（推荐）**：在 Steam 创意工坊订阅，然后启动游戏。
Steam 会自动把 mod 下载到位，不需要手动放文件。

**手动安装**（没在用 Steam / 创意工坊下不下来时）：

1. 找到游戏目录。Steam 里右键游戏 →「管理」→「浏览本地文件」，
   路径一般长这样：
   `C:\Program Files (x86)\Steam\steamapps\common\Teamfight Manager 2`
2. 把 `kpl_sab` 和 `kpl_real` 两个文件夹整个复制进游戏目录里的 `mods` 文件夹。
3. 复制完应该长这样：
   ```
   Teamfight Manager 2/
   └── mods/
       ├── kpl_sab/
       │   ├── kpl_sab.dll
       │   └── mod.mod_info
       └── kpl_real/
           ├── （数据文件）
           └── mod.mod_info
   ```
   ⚠️ 注意是 `mods/kpl_sab/kpl_sab.dll`，**不要再套一层**。
   如果变成 `mods/kpl_sab/kpl_sab/kpl_sab.dll` 游戏就找不到 mod。
4. 启动游戏，进「Mod」列表，勾选 **KPL SAB 赛制** 和 **KPL + Real LoL Teams**。

### 第二步：开档

1. 主菜单「新游戏」→ 选国家/赛区。选 **中国（CN）** 才会看到 KPL 队伍和赛制。
   选别的赛区就是这个 mod 的另外一部分（真实 LoL 战队），没有 KPL 赛制。
2. 选队界面的队伍已经按实力排好序，排在前面的就是强队。想省事直接选排第一的。
3. 开启后春季赛会自动抽签分成三组，看新闻里的「KPL 春季赛第一轮抽签」。

### 第三步：看季后赛完整赛程

原生联赛页面和日历只能显示 8 场季后赛（游戏的硬限制），完整是 16 场。
所以本 mod 加了两个入口：

- 点屏幕底部的 **「季后赛」按钮**；
- 或者按键盘 **F8**。

面板会显示全部 16 场，带轮次、日期、双方队徽和实时比分，每秒自动刷新。
只读存档，不会改动任何比赛结果，放心随时点开看。

## 注意事项

### 必须知道的

1. **必须开新档**。老存档里的联赛结构、选手名单都是按旧版生成的，
   装上新版 mod 再读老档会出现分组错乱或者名单不对。
   想看新的名单和能力值，请开一个新的存档。
2. **中国赛区才是 KPL**。选美国/韩国/欧洲等赛区时没有 S/A/B 分组，
   那边是普通的联赛 + 真实 LoL 战队。
3. **S组 / A组 / B组 是同一个联赛级别**。这是故意这么设的：游戏引擎只要
   认为 A 组是二级联赛，就会自动生成升降级赛、降级履历和赞助惩罚，
   所以三个组统一成顶级联赛。B组升 K甲 的升降级仍然保留。
4. **球员名单是固定的**。同一支队每开一个新档都是同一批人、同一套能力和潜力，
   不会因为你重开就换人。换赛区、换档都一样。

### 容易踩的坑

5. **不要和别的改中国赛区的 mod 同时开**。比如别的 KPL 换皮包、改选手数据的包，
   一起开会互相覆盖联赛和名单，表现为分组错乱或者队名变回英文。
6. **Steam 订阅后不要再用旧的手动文件夹**。如果你之前手动放过一份 `mods/kpl_sab`，
   又从创意工坊订阅了，会有两份同名 mod 打架。删掉手动的那个。
7. **选队列表排序变化不是 bug**。开档时按五个位置最强评分之和排序，
   所以名单更新后（比如 1.6.0 重算了能力值）排位会变。
8. **能力值和现实有差距是正常的**。数据来自官网公开的赛季统计：
   分均伤害、分均承伤、KDA、胜率、参团率、英雄池这些。
   官方不公开的部分（比如选手的临场指挥、BP 贡献）没法量化，只能靠荣誉补偿。
   所以别拿评分去跟社区排名一一对照。
9. **季后赛面板的按钮不见了**？按 F8 试试；还不行就是 mod 没加载成功，
   回 Mod 列表确认 `kpl_sab` 是勾选状态、版本号能看到。
10. **游戏更新后 mod 失效**。本 mod 用的是 stable ABI，一般小更新不用重装；
    但大版本更新后需要重新订阅 / 重装一次。

### 卸载

- 创意工坊订阅的：取消订阅，Steam 会自动删。
- 手动装的：删掉游戏目录 `mods` 下的 `kpl_sab` 和 `kpl_real` 文件夹。
- 存档里已经生成的 KPL 分组和队名不会消失（它们已经写进存档了），
  但会变回引擎默认行为。

## 安装

## 从源码构建

`kpl_sab` 是 stable-ABI 原生 mod，依赖游戏自带的 `mod-api-stable`：

```
Teamfight Manager 2/
└── mod-sdk-stable/
    ├── mod-api-stable/     <- 游戏自带
    ├── kpl_sab/            <- 本仓库的 kpl_sab 目录放到这里
    └── kpl_scout/          <- kpl_scout 同理
```

```sh
cargo build --release
cp target/release/kpl_sab.dll ../../mods/kpl_sab/kpl_sab.dll
```

也可以直接用游戏目录里的 `TFM2ModUploader.exe`：选择 `kpl_sab` 文件夹，
它会自动找到 `mod-api-stable`、构建并上传创意工坊。

## 兼容性

- 基于游戏 base 版本 **0.7.0**，stable ABI（游戏更新后一般不需要重编）。
- 只改存档内的联赛/比赛/新闻记录，不改可执行文件。
